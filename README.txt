mojeTRP landing page
====================

Obsah:
- index.html
- assets/ (logo + mobilní screenshoty)

Nasazení na VPS, pokud už /var/www/mojetrp existuje:

  sudo cp -r /cesta/k/mojetrp_landing/* /var/www/mojetrp/
  sudo chown -R www-data:www-data /var/www/mojetrp

Nebo soubory nahraj přímo do /var/www/mojetrp.
